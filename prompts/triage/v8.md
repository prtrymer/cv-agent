- fullstack: owns features across browser UI and server side, whatever the server language except Java. A full-stack
  role on a stack the candidate lacks is still fullstack — the missing stack lowers the score, it doesn't change the family.
- java-fullstack: owns features across browser UI and a server side in Java (Spring, Jakarta EE) — e.g. Java backend
  plus React / Angular / TypeScript UI. Use it whenever a full-stack role's server language is Java.

- backend: server side in TypeScript / JavaScript (Node.js, NestJS, Express).

- devops: the core daily work is infrastructure and reliability — DevOps, SRE, platform or cloud engineering (CI/CD, Kubernetes,

- other: anything else — backend-only roles in Python, Go, .NET, PHP or Ruby, mobile, data, ML, QA, management.
